# AI-PRIVACY-POLICY-GENERATOR
AI Privacy Policy Generator is a full-stack web app (HTML, CSS, JavaScript, PHP, MySQL) that scans any live website URL for form inputs and generates a customized GDPR/CCPA/DPDP-compliant privacy policy via the Gemini API, embeds a scannable website verification QR code .we can save, view, delete policies in PDF, DOCX, and TXT formats.
